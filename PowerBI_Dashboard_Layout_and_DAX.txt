# POWER BI DASHBOARD — EXACT BUILD SPECIFICATION

## Page
Page name: `Fitness Business Dashboard`
Canvas: 16:9
Suggested page size: 1280 x 720
Background: very light gray / near-white
Header: dark navy
Accent: teal
Secondary accents: amber and red

## Data model
Table name: `Fitness`
Columns:
Duration, Date, Pulse, Maxpulse, Calories, Cal_per_Min, Intensity, Week, Month, Weekday

## Data types
Date = Date
Duration, Pulse, Maxpulse, Week = Whole number
Calories, Cal_per_Min = Decimal number
Month, Weekday, Intensity = Text

## DAX MEASURES
Total Sessions =
COUNTROWS(Fitness)

Total Calories =
SUM(Fitness[Calories])

Avg Calories per Session =
DIVIDE([Total Calories], [Total Sessions])

Avg Calories per Minute =
AVERAGE(Fitness[Cal_per_Min])

Avg Duration =
AVERAGE(Fitness[Duration])

Avg Pulse =
AVERAGE(Fitness[Pulse])

Max Recorded Maxpulse =
MAX(Fitness[Maxpulse])

## OPTIONAL VALIDATION MEASURE
Calculated Calories per Minute =
DIVIDE(SUM(Fitness[Calories]), SUM(Fitness[Duration]))
